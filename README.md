# Synapse – Downloads

Hier liegen nur die fertigen Installer von **Synapse** (kein Quellcode).

**Neueste Version herunterladen:**
[Synapse-Setup.exe](https://github.com/wrzelias16/synapse-updates/releases/latest/download/Synapse-Setup.exe)

1. `Synapse-Setup.exe` herunterladen und ausführen.
   Windows warnt evtl. („Der Computer wurde durch Windows geschützt“) → **Weitere Informationen** → **Trotzdem ausführen**.
2. Beim ersten Start Vor- und Nachnamen eingeben und auf die Freigabe warten.
3. Updates kommen danach automatisch – Synapse meldet sich, wenn eine neue Version bereit ist.
